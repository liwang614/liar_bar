# 骗子酒馆：猫狗羊（Web 多人桌游）

真人联机桌游《骗子酒馆 / Liar's Bar》「猫狗羊」变体：吹牛 + 质疑 + 俄罗斯轮盘式惩罚的心理博弈。React 18 + TypeScript + Vite + Tailwind + zustand 前端；**自建 Node WebSocket 权威服务器**后端。

> **后端说明**：原计划用 Firebase，但 Firebase/Google 服务在中国大陆需翻墙、手机端常连不上。已改为**自建 WebSocket 服务器**——国内必通、无需任何账号、不花钱。纯函数规则引擎与后端完全解耦，未受影响。

---

## 架构

- **引擎**（`src/engine`）：纯函数、零依赖。`reduce(state, action, rng)` 是唯一状态机，所有随机走可序列化 RNG，单测可复现。21 项 vitest 单测覆盖全部规则条款。
- **服务器**（`server/`）：**权威**模型——服务器内存持有引擎全状态，永远是裁判；只向每个客户端下发**其本人手牌** + 公开房态 + 事件流。比原 Firebase「裁判客户端」方案更简单、更安全（牌面只在服务器，客户端永远看不到他人手牌）。内置**回合超时托管**：超时自动替该玩家随机出 1 张，连续 3 次自动出局——锁屏/掉线不再卡死。
  - `server/gameServer.ts`：房间中枢（创建/加入/准备/开始/出牌/质疑/重连）。
  - `server/vitePlugin.ts`：开发时把 ws 服务挂到 Vite 同一端口（`/ws`），手机访问 5173 即可，无需额外端口/防火墙。
  - `server/standalone.ts`：生产/远程用独立服务器，托管 `dist` + `/ws`。
- **前端**（`src/net`）：`client.ts` 单 WebSocket 连接，自动重连 + 断线自动重新加入恢复视图；`protocol.ts` 为前后端共享的消息与公开数据类型。

## 本地运行（电脑 + 手机同局域网）

```bash
npm install
npm test          # 引擎单测（21 项全绿）
npm run dev       # 前端 + 游戏服务器同跑在 5173
```

- 电脑浏览器：`http://localhost:5173/`
- 手机：和电脑连同一 Wi‑Fi（或电脑连手机热点），用电脑的**局域网 IP** 打开，例如 `http://192.168.x.x:5173/`
  - 查 IP：`ipconfig` 看「WLAN」那一行的 IPv4；或看 `npm run dev` 打印的 Network 地址里那个 `192.168.*` / `10.*`。
  - 手机别用 UC/QQ/夸克等带「云加速」的浏览器（会走云代理连不到局域网），用 Chrome/Edge/Safari 直连。

创建房间拿 6 位房间码 → 另一台加入 → 双方准备 → 房主开始。

## 远程联机（和不在同一网络的朋友玩）

把服务器部署到一台**国内云服务器**（任意 VPS）：

```bash
npm run build                 # 产出 dist/
# 将整个项目拷到服务器，安装依赖后：
PORT=8080 npm run server      # 托管 dist + /ws 同端口
```

朋友访问 `http://你的服务器IP:8080/` 即可。（用域名 + 80/443 对外需备案/反代，按需自行配置 Nginx。）

## 消息协议（`src/net/protocol.ts`）

- 客户端 → 服务器：`create` / `join` / `ready` / `start` / `action`(PLAY_CARDS·CHALLENGE·TIMEOUT·FORFEIT) / `leave`
- 服务器 → 客户端：`joined` / `state`(公开房态 + 本人手牌 + 事件流) / `error`
- 身份：客户端在 localStorage 生成持久 `uid`，断线重连凭它自动回座。

## 玩法调整（相对原始 R-x 条款）

按用户要求做的几处规则/体验调整：

- **命运牌 6 张 = 4 安全 + 2 炸弹**（原 1 炸弹；改 `GAME_CONFIG.FATE_BOMBS`）。
- **死亡判定改为「由对方揭牌」**（原 R-13 自动随机翻）：轮到谁受罚，进入 `fate` 阶段，由**对方**点选他面前一张面朝下的命运牌翻开，翻到炸弹才出局——更有博弈与悬念。超时未翻由服务器随机代翻。
- **再来一局**：对局结束后任意成员可在结算页点「再来一局」，同房重开、保留座位与胜场，全员复活，无需退回首页。
- **累计胜场**：每个玩家的胜场存在客户端 localStorage，**跨房间携带**；加入任意房间都会带上并展示，胜利后 +1。

## 规则裁定记录

R-x 条款为权威定义。以下为条款未覆盖、按 Liar's Bar 电子版惯例自行裁定之处：

1. **超时自动出牌**：从手牌随机抽 1 张面朝下打出、不质疑（R-8 + §5.1）；连续 3 次 → FORFEIT 出局。由服务器倒计时统一托管。
2. **R-14(b) 全部打空后的首家**：该小局无判定，`lastJudgedUid` 沿用上一次；若整局从未判定则按 R-7 随机首家。
3. **中途退出/掉线**：主动退出对局中玩家 → 立即 FORFEIT 出局；仅断线（锁屏）则保留座位，轮到他时由超时托管自动出牌，连续 3 次后才 FORFEIT。
4. **playId**：由 `小局号-uid-剩余手牌数` 派生，小局内唯一且确定。
5. **权威模型**：服务器是唯一裁判，牌面只存在于服务器内存；客户端只能看到自己的手牌和公开房态，从协议层杜绝看牌作弊。

## 项目结构

```
src/engine/      纯函数引擎（config/types/rng/game/reduce/helpers）+ __tests__
src/net/         protocol（前后端共享类型）+ client（ws 客户端）
src/store/       zustand：连接、房态、手牌、事件流
src/pages/       Home / Lobby / Game / Result
src/components/  FateRow / Toast / 文案与视觉常量
server/          gameServer（房间中枢）+ vitePlugin（开发同端口）+ standalone（生产）
```
